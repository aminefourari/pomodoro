# 🍅 Pomodoro Timer

A beautiful macOS menu bar Pomodoro timer with focus music integration.

![macOS](https://img.shields.io/badge/macOS-13.0+-blue)
![Swift](https://img.shields.io/badge/Swift-5.0-orange)
![License](https://img.shields.io/badge/License-MIT-green)

## Features

- ⏱️ **Pomodoro Timer** - 25/5/15 minute work/break cycles
- 🎵 **Focus Music** - Built-in lofi radio streaming during work sessions
- 🔔 **Smart Notifications** - 5-minute warning and session complete alerts
- ⚙️ **Customizable** - Adjust work/break durations
- 🎨 **Beautiful UI** - Native macOS design with blur effects

## Installation

### Download
Download the latest `.dmg` from [Releases](../../releases)

### Build from Source
1. Clone the repo
```bash
git clone https://github.com/aminefourari/pomodoro.git
cd pomodoro
```

2. Open in Xcode
```bash
open Pomodoro.xcodeproj
```

3. Build and run (⌘+R)

## Usage

1. Click the timer icon in your menu bar
2. Press the play button to start a work session
3. Enable **Lofi radio** in Settings for focus music
4. Get notified when it's break time!

## Requirements

- macOS 13.0+
- Xcode 15.0+ (for building)
